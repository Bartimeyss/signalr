# Live Pulse demo

Мини-демо для лекции: несколько вкладок видят общий счётчик подтверждённых
проверок релиза без обновления страницы.

```bash
dotnet run --project LivePulseDemo/LivePulseDemo.csproj
```

Открой показанный URL в двух вкладках и нажми «Подтвердить проверку» в одной.
Счётчик изменится в обеих. Это серверный Blazor: пользовательское событие идёт
на .NET-сервер, а обновлённая разметка возвращается во все открытые вкладки по
SignalR. В проекте нет пользовательского Hub — это специально, чтобы показать
SignalR, который Blazor Server использует внутри, и не дублировать практику
BadNews с `CommentsHub`.
